# pyhwinfo

Python module for retrieving hardware information

## Installation

1. Download and unpack ZIP-file to any folder
1. Open the folder in Windows Explorer where you unzipped the files
1. Run script `run.py` using any of the following methods:
    1. Running via the "Open with" dialog:
        1. Find file `run.py`, hover over this file and hold the right mouse button to bring up the context menu
        1. Select "Open with", select "Choose another app" or "Choose an app on your PC"
        1. In the dialog box "Open with" that appears, go to the folder where you unpacked the ZIP-file
        1. In the same dialog, open the `python` directory, select file `python.exe` and click the "Open" button
    2. Running via LNK-file:
        1. Find file `run.py`, hover over this file and hold the right mouse button to bring up the context menu
        1. Select "Create shortcut" to automatically create file `run - shortcut.lnk`
        1. Find file `run - shortcut.lnk`, hover over this file and hold the right mouse button to bring up the context menu
        1. Select "Properties" to open the dialog "Properties: run - shortcut"
        1. Change the value of field `Object` to the following line: `<working_folder>\python\python.exe  run.py`
        1. Close the dialog by clicking the "OK" button
        1. Double click on the created LNK-file
    3. Running via BAT-file:
        1. In any text editor, create a file `run.bat` in the open folder and specify the following line as its contents: `python\python.exe  run.py`
        1. Double click on the created `run.bat`

## Usage

* Run `!START.bat` or `run.bat`
